The Text Inspector

The Text tab in the inspector describes the active document as a whole. This tab has three facets. Overview shows stats for your document, including counts of sentences and words, readability figures, vocabulary, sentence structures, and charts of word class frequencies, grammatical functions, and phrase counts. Details contains the attribute values and tags associated with the document, while Bookmarks shows the passages that you bookmarked in your document.

Statistics describe only the surface of a text. They can help you characterize the document, allow you to choose documents for closer reading, and help you detect anomalies within a dataset (such as transcripts where there never was a break between sentences). However, statistics cannot inform you of what someone intended with the writing, nor can they give insight into why two op-eds differ.

Key terms#

When indexing documents, LemmaLoom parses them into their constituent sentences and tokens; tokens refer to individual words and punctuation (see Chapter 21, Analysis and Indexing). Statistics are derived from this division.

  • Word refers to any token that is not punctuation or a symbol. Number tokens will also qualify as words.
  • LemmaLoom recognizes unique words according to each word’s dictionary form, or lemma; model and models count as one unique word, and so do was and were. These terms are known in linguistics literature as types, giving rise to the term type-token ratio.
  • A syllable count represents a rough guess made solely based on the orthography of each word.
  • Long words are defined by LemmaLoom as having more than six letters.
  • Stopwords are words found in a predetermined list for each language; these refer to commonly used words such as the, of, and is. Words not found in this list are termed content words.
  • Shares refer to the proportions expressed as percentages. Given 17 stopwords out of 30 total words, the resulting share will be , shown as 57%.

Opening the Text tab#

The examples throughout this chapter come from “Climate Debate”, the bundled example project of this guide; you can add the example project to your library with File ▸ Import ▸ Example Project (see The example project in Chapter 1, Introduction). See below for the Text tab of “Running Out of Time”, an activist op-ed with 910 words spread out over 65 sentences.

There is only one column in the Overview facet. It starts from the top and includes five sections of measures (namely Overview, Readability, Lexical, Syntax, and Structure), followed by three bar charts (Parts of speech, Functions, and Phrases). The first section, titled Overview, contains simple counts related to the text, sharing its title with the facet.

To open the Text tab:

  1. Open a document in the reader.
  2. If the inspector is hidden, choose View ▸ Toggle Inspector (⌃⌘I).
  3. Click the book icon at the top of the inspector, or choose View ▸ Inspector ▸ Text (⌥⌘1).
  4. Click Overview, Details, or Bookmarks in the row of facets below the icons.

By default, your document shows its Text tab and Overview facet until you manually change it. Changes to your tabs and facets are remembered independently by each document whenever you switch document tabs. When viewing documents side-by-side in split view mode, the inspector will show the document in the currently active pane. Click the other pane to inspect the statistics of the other document, although whichever tab and facet had been selected previously will remain intact. Inspectors will remain closed during detail views and when viewing a set; separate inspectors will appear per individual document window.

Statistics need an indexed document in order to display. If indexing isn’t complete yet for the first section of text, then you’ll see the placeholder Statistics become available when indexing completes. The Details facet does what it’s supposed to do regardless of whether or not there are statistics available yet. While indexing occurs, statistics relate strictly to the already processed portion. Document statistics work only with English, German, and Chinese documents; for other languages, the placeholder remains.

The Details facet#

Every document in the “Climate Debate” example project comes with values for four attributes. Values for the “Stance” attribute denote whether the text came from activists, skeptics, or neutral sources. “Readership”, “Publication Date”, and “Outlet” denote the size of the audience, when the article was published, and where, respectively. In the Details facet on the “Running Out of Time” document, Attributes shows “Stance” as “Activist”, “Readership” as 412,000 readers, “Publication Date” as August 21, 2024, and “Outlet” as “The Northern Herald”. Below the Attributes section, under Tags, is the only tag for this document, “op-ed”.

Attributes lists every existing attribute-value pair for the currently active document, providing editing fields for the attributes. It is a place for assigning and modifying attribute values for a single document as you browse through it. For setting attribute values for several documents simultaneously, please see Setting one value for many documents in Chapter 8, Sets, Groups, Tags, and Attributes.

When you need to set a value for an attribute not listed in the current list of attributes for a document:

  1. Type the attribute’s name in the field below the list. LemmaLoom suggests names already in use in your projects, with their type, as in “Outlet” · Text.
  2. If the project has no attribute of that name, choose a Type. For a Picker, also type its choices, one per row.
  3. Click Add Attribute, or press Return.
  4. Enter the value in the new row.

An attribute is listed only once in each document. If you attempt to add an attribute the document already lists, Add Attribute remains disabled, and its tooltip reads Already added.

When clearing a value, click the remove button at the end of the value’s row (Remove attribute). Tags are inputted via the field that reads Add a tag. Begin typing the desired tag and then press Return, or type a comma after a tag to move to the next one. Suggestions for existing tags appear while typing, and to delete a tag, click the × on it.

All edits happen immediately and affect the document’s translations too. Editing values or tags can both be undone using Edit ▸ Undo Set Value and Edit ▸ Undo Edit Tags (⌘Z); undoing an addition of an entirely new attribute happens via Edit ▸ Undo Add Attribute. For further reading about Entering values and Tagging a document, please refer to Chapter 8, Sets, Groups, Tags, and Attributes.

Exporting the statistics#

To export all statistics in a document to a single file:

  1. In the Overview facet, find the heading of the Overview section, at the top of the facet.
  2. Click the export button at the right of the heading (Export as CSV).
  3. Choose a name and a folder, and click Save. The name suggested is the document’s title followed by -statistics, as in Running Out of Time-statistics.csv.

The file has three columns called Section, Measure, and Value, and one row per measure displayed, plus one row per bar of each of the three charts. The value displays the same way as it does in the inspector (rounding and units included), as in 57% or 10.0 words.

There is an export button on the right side of each chart’s heading. This opens a menu containing options for export in PNG and PDF formats (with the chart’s title), and CSV for category counts alone (in Category and Count columns).

The default naming suggestion combines the document and chart titles together, for instance Running Out of Time-Parts of speech.png.

Only one document can be viewed in the inspector at once. In order to consolidate statistical figures of several documents into spreadsheet form for comparative purposes, export each document into a separate file first, and then combine the files, removing the unit symbols and % signs before your calculations.

Finding documents by a statistic#

Each measure shown in the table above can function as a rule in a query. A query of this nature allows you to select particular documents that fit the rule, e.g., those that are more difficult to comprehend than plain English, or those containing an exceptionally large proportion of passive sentences.

The following image shows a query of this sort within the “Climate Debate” project, seeking documents having a Flesch Reading Ease below 60 (the lower boundary of Flesch’s plain English range), yielding a single document called “Heat Wave Report 2024”.

To query documents based on statistics:

  1. In the navigation sidebar, click Queries under Project.
  2. In Find, choose Library · Documents.
  3. In Where, click Add and choose Add Rule.
  4. Click the field, choose Statistic, and choose the measure, such as Flesch Reading Ease.
  5. Choose a comparison, such as is less than, and enter the number in Value.

The following are some rules concerning statistic fields in queries:

  • The Statistic field is only available in queries made on document sets, projects, and All Projects. While all statistics fields are provided in queries, the only statistic fields in a smart set are Tokens, Sentences, and Characters, which LemmaLoom tracks once a document has been indexed. Tokens counts punctuation marks too; hence, Tokens will be greater than Words. Please refer to Fields in Chapter 15, Building a Query to know where each statistic field is provided.
  • The comparison made in a query is against the unrounded number. For example, a score displayed as 86.7 may actually be 86.705; therefore, use comparisons such as is less than, is at least, or is between in place of is.
  • Measures shown as percentages, Hapax ratio included, are represented as fractions between 0 and 1 in queries. When searching for documents where the Lexical density is at least 45 percent, the number to input should be 0.45.
  • A rule skips documents that have no value for its measure. Measures such as Flesch Reading Ease are calculated for English documents only; thus, a rule like is less than 60 skips any non-English documents during evaluation. Documents currently being indexed are excluded from the evaluation until their statistics become available.

When the statistics are computed#

LemmaLoom calculates statistics on documents and stores them alongside the documents. Statistics on documents are used in the Text tab and the Statistic field in queries, which means that both will always show consistent statistics. Document statistics pertain to the entire document although only annotated sentences may be shown in the reader (see Showing only annotated sentences in Chapter 6, Lenses).

LemmaLoom recalculates the statistics only when changes are made to the document’s text or indexing configuration. Changes include editing and saving the document’s text, altering the document’s language settings, and changing the patterns that exclude text from indexing. Should the statistics not yet be calculated when you visit the Text tab, a spinner icon will appear momentarily until LemmaLoom finishes processing.

Statistics for a translation document, e.g., “Running Out of Time (German)”, will be unique to the translation document and be based on calculations using the measures of its own language.

Words and unique words#

Words refer to indexing tokens without punctuation marks and special characters, according to whatever indexing sees as constituting a token in the language of interest. In English, for instance, indexing splits contractions (don’t = do + n’t), and hyphenated words get split at the hyphen punctuation mark (eighty-four = eighty + four). Since Chinese text contains no word separations in the written form, indexing decides where a word stops and the next starts for counting purposes.

Unique words ignores the capitalization of words, thus making The (capitalized at the beginning of sentences) and the (in the middle of a sentence) equal to each other as a unique word.

Text excluded from indexing, such as timestamps in a transcript, counts only under Characters and, when it forms a paragraph of its own, under Paragraphs (see Text excluded from analysis in Chapter 21, Analysis and Indexing).

Note

The word count on the far-right side of the reader’s status bar includes punctuation marks, making it higher than the count for Words in the inspector, which does not count punctuation marks. Queries which count per 10,000 words base their count on the inspector instead.

Sentences and paragraphs#

Sentence boundaries are usually indicated by periods, question marks, and exclamation marks in written texts. In transcripts, sentence boundaries occur anywhere such punctuation is inserted during transcription.

Paragraph breaks are based on the line breaks in your text. If there is a blank line found anywhere in your text, then blank lines function as paragraph breaks, whereas adjacent lines with a line break separating them form a single paragraph. Otherwise, a line break always results in a new paragraph beginning. Blank lines refer to lines containing nothing but whitespace. Transcripts produced by LemmaLoom automatically insert paragraph breaks if there is any change in speaker identity or any pause lasting more than one and a half seconds.

Letters, characters, and syllables#

A letter count counts each alphabetic letter in the text, including any Chinese characters. Digits, punctuation marks, and apostrophes do not count toward the letter count measurement. Among all readability formulas, ARI is the only formula that takes into account letters and digits together.

The estimation of syllable count relies on counting consecutive vowel clusters within a word, where vowels include the five letters a, e, i, o, and u, plus the letter y in English and German, and the umlauts ä, ö, and ü in German. Consider heat (ea), again (a and ai), and families (a, i, and ie). When estimating English syllable count, a final e after other vowel clusters is considered silent, except for words ending in le. As a result, words such as wave and were are estimated with one syllable while people has two syllables. Each word must contain at least one syllable; therefore even 2050, which has no vowels, has one syllable.

Words like warned, which is estimated with two syllables due to its -ed suffix, or science, which is estimated as one syllable, not two, are examples of error cases. Words with consecutive a, y, and o vowels such as mayor, estimated at one syllable, are another error case. In German, the word Familien is incorrectly counted with three syllables due to the presence of the cluster ie. Such errors may partly cancel out in practice when calculating overall scores for whole documents.

Readability#

Readability formulas calculate the ease of readability of a text based on just two metrics (sentences’ lengths and words’ lengths), which are relatively straightforward measures to extract objectively from text. Sentence length correlates directly with higher demand on working memory capacity, so longer sentences are harder. The longer words are, the rarer and more abstract they will likely be too. The relationship between the two lengths and the comprehension levels of test subjects (e.g., children at school) was found during studies where test texts were presented to individuals and their comprehension ability assessed. The seemingly bizarre and precise constant factors such as 206.835 come from fitting a mathematical function to these observations.

In a study, you could use readability scores to compare the texts of any media organization to others’, or even assess which side of an argument uses simpler or more complicated linguistic structures than the other.

Grade levels provided by certain formulas describe the necessary schooling years to be able to comprehend the given text adequately without significant effort or confusion. When grades are given without specifying another school system, assume them to belong to the American educational system, where grade 8 equates roughly to age 13 or 14.

Even a sentence composed fully of shorter words can still be hard to understand, and familiar and understandable technical vocabulary still counts by its length in these formulas regardless of the actual understanding of a term.

Chinese measures#

The formulas above measure readability in relation to syllables or letters in the case of alphabetic languages. Since the metrics don’t work for Chinese texts, the Readability section of a Chinese document provides three alternatives below Avg. sentence length:

  • Characters per sentence measures the ratio between the count of Chinese characters and sentences in your text. Non-Chinese alphabet letters also count here. Furthermore, numbers written in characters will contribute toward character count; for example, 十二 equals two characters. However, numbers written using Arabic numerals such as 12 aren’t considered Chinese characters. As usual, punctuation doesn’t increase character count either.
  • Avg. word length is measured in characters. This metric calculates character count divided by word count. Documents containing many two-character words such as 气候 or 邻居 receive higher scores compared to ones where single-character words are common.
  • Particle density measures how many particles occur in every hundred words. Particles include words that are annotated with the Particles lens, which are verbal 了, 着, and 过 particles; 的, 地, and 得; and classifiers such as 个 (see Constructions and Particles (Chinese) in Chapter 6, Lenses). Sentence-ending particles such as 吗, 呢, and 吧 aren’t counted.

Vocabulary#

The Lexical section deals with the words in your document. Through these measures, you get insights regarding whether your document tends to rely heavily on recurring vocabulary or has a varied vocabulary. The type-token ratio, for instance, will inform you about how many unique lemmas were used relative to the total number of words in your text. In it, as in MATTR and the hapax ratio, different forms of a lemma will still be counted as one.

MATTR#

MATTR, or moving-average type-token ratio, quantifies lexical diversity irrespective of the size of the document. In LemmaLoom, MATTR begins with finding the type-token ratio in a sliding window of the first hundred words of a text, shifting one word along, finding the type-token ratio for words 2 to 101, and so on up until the very end. MATTR is therefore the mean of those ratios.

Lexical density and stopword share#

Stopword share is the proportion of words in a document that are in the list of stopwords for that document’s language. Conversely, Lexical density is the proportion of words in a document that are not stopwords; thus, both proportions add up to 100 percent.

Consider the example passage, for instance, which consists of thirty words. There are seventeen stopwords here, namely we, were, by, the, again, and this in the first sentence; so, the, for, a, and, and could in the second; and the, that, our, had, and up in the third. Natural speech tends to have less lexical density than edited writing does, due to pronouns and auxiliaries. Finding that the stopword proportion in a transcription is low compared to natural speech can be a sign that the transcript was summarized rather than transcribed word for word.

Lists of stopwords come built in, and they are fixed per language:

  • The list of English stopwords contains around 160 words including articles, pronouns, prepositions, and conjunctions; conjugations of be, have, and do; modal verbs like can, should, must, and the rest; negative not and no; and common adverbs like very, also, and again.
  • The list of German stopwords contains roughly 210 words, including, besides articles, pronouns, prepositions, and auxiliaries, the modal particles ja, doch, mal, eben, and halt.
  • The list of Chinese stopwords contains about 150 words, among them 的, 了, and 是; pronouns; 不 and 没有; and common prepositions and adverbs.

A word qualifies as a stopword if it matches the list in terms of its lemma or token form. Content words that can appear to be function words include nobody in the example passage. The query field Stopword uses the same lists.

Note

The measure of lexical density that linguists usually take depends on parts of speech, considering only nouns, verbs, adjectives, and adverbs to be content words. LemmaLoom’s measure of lexical density uses its stopword list. It is therefore not directly comparable to figures based on parts of speech.

Syntax#

The Syntax section analyzes your sentences for how they are constructed beyond measuring sentence lengths. Measures include looking into the distance between words related to each other, nesting of clauses inside other clauses, and other similar measures that reveal the complexity of the sentence structure. They rely upon two parts of the grammar analysis.

The dependency analysis refers to analyzing the relationship between words within a sentence in terms of the head word on which each word depends. In a fair share, for instance, fair and a depend upon share. Each sentence has one root word, which does not depend upon any word (generally the main verb in a sentence). The links between words and their heads are displayed graphically via the inspector under the Grammar tab (see Chapter 11, The Grammar Inspector).

The phrase analysis groups the words of a sentence into phrases and clauses nested inside one another.

For every word, the path upwards through its heads to the hierarchy’s root defines its depth. The number of hops needed is equivalent to the depth of the word. Depth for a sentence is calculated by finding the highest depth value among all of its words. Avg. tree depth is merely the average depth of sentences in a document.

Passive sentences#

Passive sentences refers to the proportion of sentences within your document that have one or more occurrences of passive constructions. Multiple occurrences of passives in a single sentence will not change the count. For instance, in a document with 40 sentences in total, and six of those having passives, the proportion becomes .

What counts as a passive depends on the language:

  • In English, the grammar analysis detects the subject and auxiliary verb in a passive sentence; one example is this from “Heat Wave Report 2024”, This report was prepared by the agency’s climate monitoring service.
  • For Chinese, any occurrence of a sentence with 被 and other recognized passive constructions will be included, as with the 被 passive aspect of the Constructions lens.
  • In German, a passive with werden and a past participle counts whether or not the agent is named, as in Dieser Bericht wurde erstellt and Dieser Bericht wurde von der Klimaüberwachung des Amtes erstellt. A passive with sein counts only when a von or durch phrase names the agent, as with the Passive voice device of the Rhetoric lens.

Occasionally, passives omit information on who performed an action. In “Heat Wave Report 2024”, for instance, responsibility for checking on older people living alone was not clearly assigned.

Structure#

The Structure section contains three metrics.

Dialogue share calculates what percentage of words occur between double quotation marks. Consider, for instance, the artificial sentence My neighbor always said, “Our summers are mild.” Four out of eight words occur in quotations here, making a dialogue share of 50%. In news reports, such as “Carbon Tax Debate”, quotation marks are used to highlight direct quotations from speakers, and the share shows how much of the text overall is other people’s words. LemmaLoom pairs the quotation marks to estimate the share:

  • Straight quotation marks (") open and close sequentially.
  • Curly quotation marks open with “ and close with ”. In German documents, „ opens and “ closes.
  • « and the Chinese corner brackets 「 and 『 open, and », 」, and 』 close. In German documents, » opens and « closes.
  • Single quotation marks are ignored.

An unpaired quotation mark causes all subsequent words to count as quoted. A surprisingly high value often suggests there may be a rogue quotation mark somewhere in the document.

Questions and exclamations calculates the percentage of sentences ending with a question mark or an exclamation mark. It includes the full-width characters in Chinese texts. Note that only sentences whose final token is either an exclamation or question mark qualify; sentences ending with a closing quotation mark after the question mark are excluded. In a document containing 80 sentences, among which there are 18 questions and 2 exclamations, Questions and exclamations amounts to . A high value in opinion pieces and speeches may suggest the presence of rhetorical questions, such as the one bookmarked in “Running Out of Time”. As usual, the statistics pertain to the document’s entirety, including the host’s questions in a transcript such as “Radio Debate”.

Finally, Sentences per paragraph is obtained by dividing the total number of sentences by the number of paragraphs. For example, 120 sentences spread over 40 paragraphs produce a ratio of 3.0 sentences per paragraph. Transcription with LemmaLoom produces transcripts with paragraphs ending at every change of speaker and at substantial pauses; hence, the metric provides a rough idea of how many sentences speakers utter continuously.

Parts of speech, functions, and phrases#

Below the measures, three bar charts show word and phrase distribution across categories in your selected document. Each row includes the category name, a bar, and a number that represents how many times the category was used in the selected document. Note that these statistics do not contain unused categories; the bars use the standard colors of the matching lens, even when other colors were chosen in the Lenses pane of Settings.

  • Parts of speech shows word count statistics in the ten classes of the Word class lens from Noun to Interjection (see Word class in Chapter 6, Lenses). Note that all other types of words, including foreign words, are excluded from this statistic.
  • Functions represents word count statistics in each of the ten functions in the Grammatical function lens, ranging from Subject to Connector (see Grammatical function in Chapter 6, Lenses). Note that the root words without a function (typically the main verb) in each sentence are ignored, as well as words where the relationship does not fit into the ten types of grammatical functions, so these statistics’ totals will be lower than the total number of words in the document.
  • Phrases shows the phrase count for each kind of phrase in the Phrase lens from Noun phrase to Interjection (see Phrase in Chapter 6, Lenses). Note that nested phrases each count, e.g., in our valley would count as a prepositional phrase and our valley would be counted once more in the noun phrase category, while clauses are tracked separately under Syntax.

The Bookmarks facet#

The Bookmarks facet displays the document’s bookmarks ordered by position in the document. In “Climate Debate”, for instance, “Running Out of Time” has 1 bookmark located in its final paragraph, specifically at the question What exactly are we waiting for? with the comment “Rhetorical question at the turn to the closing appeal”. The heading displays how many bookmarks are associated with the document, which is why the heading is Bookmarks (1) in this case. For instructions on bookmarking, refer to Bookmarks in Chapter 7, Coding.

Each row lists:

  • a bookmark icon in the color of the bookmark, or gray if it has No color;
  • the comment of the bookmark, or, if there isn’t a comment, the bookmarked text itself up to three lines long;
  • and the location of the bookmark, like ¶10·5 for the fifth sentence of the tenth paragraph. Hovering the mouse pointer over this location will reveal it in full, as in Paragraph 10, sentence 5.

Clicking on a row navigates to the bookmark. Should only annotated sentences appear in the reader and not the selected bookmark, everything else in the document gets displayed before navigating to the bookmark.

Above the list is the Search field. Typing anything in this field filters the list to the bookmarks whose comments or text contain what you typed; case sensitivity doesn’t play a role here. Nonetheless, the number in the heading counts all the bookmarks regardless of this action.

To change a bookmark’s comment or color:

  1. Right-click its row and choose Edit.
  2. In the Edit Bookmark dialog, which shows the bookmarked passage, change Comment (optional) or Color.
  3. Click Save.

To remove a bookmark, right-click the row associated with it and select Delete. Alternatively, click Delete at the bottom of the Edit Bookmark dialog. Your changes are immediate; use Edit ▸ Undo Remove Bookmark (⌘Z) to restore a deleted bookmark. Edit ▸ Undo Edit Bookmark (⌘Z) will undo an edit action performed on a bookmark.

If there were translations available for the document where you marked a bookmark, then that bookmark exists in every translation. It is linked to the matching passage in each translation; edits and deletions of bookmarks happen across all of them. When creating bookmarks based on hits in a query (Bookmark Hits…), the resulting bookmarks will show up here just as regular bookmarks do (see Bookmark Hits in Chapter 18, Using Query Results).

Bookmarks can be exported by clicking the export button at the right of the heading (Export as CSV). The exported file includes three columns (Location, Text, and Comment) containing all of the bookmarks currently listed, which means that only matched bookmarks would be included following a search operation. The filename suggestion is the document’s title followed by -bookmarks.
